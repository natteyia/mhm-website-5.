# MHM Group — Coming Soon Page

Static, responsive one-page design. No framework or build step is required.

## Files

- `index.html` — complete page structure and styling
- `assets/` — supplied company logos

## Deployment

Upload `index.html` and the `assets` folder together to the website document root (for example, `public_html`). The page uses no external fonts, scripts, trackers, forms, contact information, or third-party assets.
